# End-to-end run on Studio Next (10 minutes)

1. Start a handover: click "Use the standard code handover checklist" (or one item of your own). Leave the
   contractor empty to run alone, or paste a second wallet's address.
2. On the handover page: fund 1 GEN (optional), then Freeze. If the contractor is another account it must Accept.
3. Register evidence from the client or contractor wallet: a public page that states the item
   (host `demo/handover-record.md`, for example as a GitHub raw URL). Tick the items it supports.
4. Optionally authorize a helper wallet; it can add up to 4 sources.
5. Verify evidence. Expect `VERIFIED` when every item is supported, `PARTIALLY_VERIFIED` if only the optional one is not.
6. Wait 5 minutes, Accept verdict, Finalize. The contractor receives the share the result earns.
7. Open "contractor record": the handover is listed under the contractor's address.
8. Negative run: register `demo/status-page-with-instructions.md` (hosted) as the only source. No item may become MET.
